# 沐枫博客 · AI 职业外脑

个人 IP 官网（落地页 + 文章详情页），静态 HTML + CSS，无后端依赖。整个 `mufeng-blog/` 文件夹可直接部署到任意静态托管（GitHub Pages / 腾讯云 / 阿里云 OSS / 服务器），或双击 `index.html` 本地预览。

> 👉 上线部署 + 百度收录教程，见 **[部署教程.md](部署教程.md)**

## 怎么发一篇新文章（详情页模板用法）

1. 打开 `article.html`，在 `ARTICLES = { ... }` 里复制 `demo` 那段，改 `id`、`title`、`category`、`body`（正文，支持 `<p>` 段落、`<h2>` 小标题、`<blockquote>` 引用、`<ul>` 列表、`<div class="callout">` 重点框）。
2. 打开 `index.html`，「近期文章」区块加一张卡片，链接写 `article.html?id=你的id`。

## 改配色

`style.css` 顶部 `:root` 里改这几个变量即可整体换肤：

- `--brand` / `--brand-deep` 主橙（成交学主色）
- `--gold` / `--gold-soft` 金色（点缀）
- `--paper` / `--paper-2` 暖纸底
- `--ink` 主文字色
